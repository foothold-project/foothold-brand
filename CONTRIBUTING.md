# Contributing

FOOTHOLD uses an approval-gated brand workflow.

1. Open an issue describing the problem, source evidence, and affected outputs.
2. Do not alter approved logo geometry, token names, semantic meanings, or claims without maintainer approval.
3. Make source changes in the canonical file, then regenerate derived files.
4. Run `npm test` before opening a pull request.
5. Include light/dark visual evidence for changes that affect rendering.
6. Label unverified content explicitly; never fill an evidence gap with a plausible claim.

AI-generated contributions must follow the same rules. The contributor remains responsible for provenance, license compatibility, and verification.
