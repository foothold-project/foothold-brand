# FOOTHOLD Symbol Reference Status

**Visual reference selected by the project owner**

`../../../foothold_logo_symbol_transparent.png`

The current `foothold-symbol.svg` is not an accurate reconstruction of that reference and must not be treated as approved symbol geometry. In particular, it changes the central vertical axis, middle separated slopes, lower V-shaped contact form, proportions, and colour treatment.

Until an accurate vector reconstruction is reviewed and approved:

- use the PNG only for internal visual comparison;
- do not replace production website or document assets;
- do not publish the current SVG as the final FOOTHOLD symbol;
- do not infer simplified geometry from the current SVG.

## Reconstruction resolved in v1

The reviewed reconstruction has been promoted into the generated v1 asset pack:

`v1/foothold-symbol-brand.svg`

It removes the PNG apex highlight, uses flat vector geometry, and preserves the four-part silhouette. The older root-level `foothold-symbol.svg` is deprecated; see `README.md` in this directory.
