# FOOTHOLD approved OSMU v1.2

These six medium-specific compositions are the human-approved v1.2 baseline exported from the FOOTHOLD Figma Master Board on 2026-08-11.

## Authority

- Canonical composition: the outlined, self-contained SVG in this directory.
- Transparent convenience output: `assets/raster/v1.2/osmu/<medium>/*.png`.
- Background-filled convenience output: `assets/raster/v1.2/osmu/<medium>/*.jpg`.
- Approval provenance: [`APPROVAL.json`](./APPROVAL.json).
- Dimensions, lifecycle, backgrounds, and hashes: [`manifest.json`](./manifest.json).

The older files under `assets/exports/v1` and `assets/raster/v1/{web,github,presentation,poster,social,goods}` are legacy composition proofs. They are preserved for compatibility and are not the current approved OSMU designs.
